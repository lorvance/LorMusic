# Проверки LorMusic Desktop 1.8.0

Проверено 15 ноября 2026 года на Ubuntu 26.10, x86-64.

- `exportRuntime createDistributable`: успешная сборка Kotlin/Compose и встроенного JRE 21.
- Проверки локального аудио: сканирование WAV, конвертация в MP3 через VLC, запись и повторное чтение тегов с кириллицей.
- Сохранение/загрузка JSON-библиотеки, плейлиста и избранного; экспорт/импорт M3U; временные метки LRC.
- Реальное воспроизведение VLC, перемотка, скорость, добавление/удаление из очереди.
- Публичный поиск: YouTube Music — 5 результатов, SoundCloud — 5 результатов.
- Реальное сетевое воспроизведение: YouTube Music продвинулся до 650 мс, SoundCloud — до 1501 мс. Проверка выполнялась с громкостью 0 и остановкой после подтверждения воспроизведения.
- Инициализация Chromium/JCEF из встроенной Java: JCEF 152.0.6.359 / Chromium 152.0.7977.83.
- Один экземпляр на профиль: второй процесс передал первому путь «Тестовый файл с пробелами.mp3» через локальное соединение с проверкой токена.
- Просмотр интерфейса: 1340×880, 1100×760 и 850×620, главная страница, меню трека, настройки, боковая очередь. Нижний плеер остаётся в видимой области.
- Linux: `.deb` распакован без установки в систему; из него успешно запущены интерфейс и все локальные проверки аудио. APT в режиме симуляции разрешил зависимости. Desktop Entry и AppStream прошли валидацию.
- Windows: NSIS собрал Unicode-установщик; `7z t` подтвердил целостность 979 файлов. В комплекте Windows x64 JRE, VLC и Windows Skiko. Исполняемые файлы Windows на Windows не запускались.
- SHA-256 главного JAR совпадает у Linux-пакета, Windows-установщика и результата Gradle. См. BUILD_PROVENANCE.json.

Личные аккаунты Google/SoundCloud не использовались. Встроенный вход, ограничения аккаунтов, регионов и приватные рекомендации требуют проверки с аккаунтом владельца. Распознавание по Shazam, все источники текстов и все действия в интерфейсе не покрыты автоматическими проверками. Часть новых диагностических сообщений пока русская.

Снимки интерфейса находятся в docs/screenshots. Тесты реализованы в DesktopChecks.kt; для повторения используйте отдельный `lormusic.dataDir`, как показано в README.
