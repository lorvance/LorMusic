# LorMusic Desktop 1.8.0

Десктопный порт LorMusic на Kotlin/JVM и Compose Multiplatform с интерфейсом Material 3: тональные поверхности, выразительные скругления, боковая навигация, постоянный плеер, отдельная панель очереди и текста.

Это первая десктопная сборка. Android-проект остаётся отдельным приложением. Сетевые репозитории YouTube Music и SoundCloud, поиск текстов, перевод, исправление тегов и алгоритм аудиоотпечатка перенесены из исходников LorMusic. Android MediaStore, WebView, MediaCodec и ExoPlayer заменены десктопными реализациями. Точный процент общего кода не заявляется.

## Возможности

- Локальные MP3, FLAC, M4A, AAC, OGG, OPUS, WAV, AIFF, WMA; добавление файлов, папок и перетаскивание в окно.
- Чтение тегов и обложек, поиск и сортировка; скрытые треки.
- Воспроизведение VLC, очередь, следующий/предыдущий трек, перемотка, случайный порядок, три режима повтора, громкость и скорость.
- Плейлисты: создание, переименование, удаление с подтверждением, добавление и удаление треков с подтверждением, импорт/экспорт M3U/M3U8.
- «Мне нравится», отдельное избранное и история прослушивания.
- Поиск YouTube Music и SoundCloud, рекомендации, «Моя волна», профили исполнителей.
- Подключение аккаунтов через встроенный Chromium; импорт сессии вручную как запасной способ. Chromium загружается при первом входе, в отдельную папку профиля приложения.
- Скачивание в MP3 через VLC, теги и обложка, выбор папки загрузок.
- Редактор тегов, обложки и текста, поиск метаданных, исправление медиатеки с просмотром предложений и распознавание по аудиоотпечатку.
- Синхронизированный LRC, сетевые тексты и перевод, переход к строке по нажатию.
- 10-полосный эквалайзер, таймер сна, светлая/тёмная тема, шесть акцентных цветов.
- Русский, английский, украинский, польский и немецкий каталоги переводов; нарисованные в коде флаги. Десктопные диагностические сообщения пока местами русские.
- Резервная копия библиотеки и восстановление; сессии аккаунтов в экспорт не включаются.

Нижний плеер имеет фиксированную высоту 114 dp. Окно можно уменьшить до 850×620; навигация, медиатека и настройки прокручиваются независимо.

## Установка

### Ubuntu / Debian, x86-64

Откройте `.deb` в системном менеджере приложений. Java включена. Пакет использует VLC из репозитория системы, зависимости устанавливает менеджер пакетов.

```sh
sudo apt install ./LorMusic-1.8.0-Linux-amd64.deb
```

Приложение появится в меню как LorMusic. Команда запуска: `lormusic`.

### Windows 10/11, x86-64

Запустите `LorMusic-1.8.0-Windows-x64-Setup.exe`. Установка выполняется для текущего пользователя, с выбором папки и ярлыками. Java и VLC включены. Удаление доступно через «Установленные приложения»; пользовательская медиатека остаётся в профиле.

Windows-пакет собран на Linux; выполнение на настоящей Windows ещё не проверялось. Исполняемые файлы не имеют платной подписи издателя.

## Подключение сервисов

Настройки → «YouTube Music и SoundCloud» → кнопка входа. Войдите на странице сервиса. LorMusic забирает только сессию выбранного музыкального сервиса. Личные аккаунты во время сборки не использовались и не проверялись.

Если Google или SoundCloud отклоняет встроенный браузер, есть ручной импорт Cookie / OAuth из вашего обычного браузера. Не публикуйте сессию и не передавайте её посторонним. Доступность потоков зависит от региона, аккаунта и ограничений сервиса; платные или недоступные записи не разблокируются.

## Управление

- Нажатие на трек — воспроизведение.
- Три точки — действия с треком.
- Ctrl + пробел — воспроизведение/пауза.
- Ctrl + ← / → — предыдущий/следующий трек.
- Кнопки справа в плеере — эквалайзер, текст, очередь, громкость.
- Перетащите аудиофайлы или папку в окно для добавления.

## Данные

Linux: `$XDG_DATA_HOME/lormusic`, по умолчанию `~/.local/share/lormusic`.
Windows: `%APPDATA%/LorMusic`.

Хранятся библиотека JSON, пользовательские обложки, настройки и отдельный браузерный профиль. Самостоятельное добавление папки не перемещает и не изменяет аудиофайлы. Редактор тегов записывает изменения в файл после сохранения; удаление файла требует отдельного подтверждения.

## Сборка из исходников

Нужны JDK 21 и сеть для Gradle-зависимостей. Android SDK и C++ не нужны.

Linux:

```sh
sudo apt install vlc binutils
bash gradlew createDistributable exportRuntime --no-daemon
python3 packaging/build_deb.py --output dist
```

Для запуска без установщика:

```sh
bash gradlew run
```

Windows: `gradlew.bat createDistributable exportRuntime`. Для стандартного `packageExe` требуется Windows и WiX, как у jpackage. Альтернатива — NSIS-упаковка из `packaging/build_windows.py`; она также работает на Linux и использует Windows JRE, Windows VLC и соответствующий Skiko.

Настройки разработки: `-Dlormusic.dataDir=/путь/к/тестовому/профилю`. Проверки не трогают обычный пользовательский профиль, если указан этот параметр.

```sh
bash gradlew exportRuntime
java -Dlormusic.dataDir=/tmp/lormusic-test -cp 'build/desktop-runtime/*' com.lormusic.desktop.MainKt --self-test
java -Dlormusic.dataDir=/tmp/lormusic-test -cp 'build/desktop-runtime/*' com.lormusic.desktop.MainKt --network-test
```

`--self-test` проверяет сканирование WAV, конвертацию в MP3, реальную запись тегов, сохранение библиотеки, M3U, LRC и реальное воспроизведение VLC с перемоткой, скоростью и очередью. Сетевой тест выполняется отдельно, без личных аккаунтов.
