# LorMusic 1.8.1 · Android · build 74

- Независимый порядок кнопок YouTube Music и SoundCloud: Настройки → Навигация. Зажмите карточку и перетащите; есть сброс порядка. Порядок входит в резервную копию настроек.
- По умолчанию: YouTube Music — библиотека, главная, моя волна; SoundCloud — чарты, главная, библиотека. Собственный порядок сохраняется.
- Общая настройка «Шапка Material 3 Expressive» действует на все вкладки обоих сервисов, включая экран входа. Сохраняются действия назад и меню аккаунта.
- Новые векторные стандартные обложки в шести цветах по предоставленным примерам.
- Новая стандартная адаптивная иконка и монохромный вариант; классическая и минималистичная иконки сохранены.
- При обычном блюре поиск находится внутри общей капсулы. В Liquid Glass и Material 3 Expressive навигации поиск остаётся отдельным.
- Раздельные баблы перенесены из бета-функций в оформление. По умолчанию включены; явно сохранённое отключение учитывается.
- Язык «Рандом» в выборе языка: «Сухарики», «Химия», «Смех» и другие русские слова. Подписи стабильны, форматы подстановок сохранены, музыка и пользовательские данные не переименовываются. Для сетевого контента используется русский.
- Сохранены последние исправления 1.8.0: отсутствие собственной анимации запуска, фиксированная высота нижних элементов, немецкий язык и скруглённые флаги.

Проверки: релизная сборка, lintVital, четыре JVM-проверки порядка кнопок и строк языка; визуальная проверка новых векторных изображений. На физическом устройстве 1.8.1 не запускалась: подключённых ADB-устройств во время сборки не было.

Адаптивная иконка рассчитана с учётом безопасной области Android: https://developer.android.com/develop/ui/compose/system/icon_design_adaptive
